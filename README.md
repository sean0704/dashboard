# 財務儀表板 (Financial Dashboard)

一個基於 **GitHub Pages** 的私有化個人與家庭資產與收支損益追蹤工具。透過「網頁輸入、AES 加密儲存、GitHub 託管」的無伺服器架構，實現**免資料庫、密碼與明文不上傳且完全自主掌控**的個人與家庭財務戰情室。

---

## 🌟 核心功能特色

### 🏛️ 1. 多維度檢視與資產負債模組 (Balance Sheet & Risk Analytics)
- **動態多成員彈性篩選**：提供核取方塊（Checkbox），可動態選擇顯示特定成員的資產與負債數據，指標與報表維持客觀中立之財務命名，不預設家庭或個人標籤。
- **4 位成員獨立管理**：支援成員1至成員4的獨立資產與負債追蹤，提供動態成員與資產類別篩選。
- **股票實質曝險與槓桿倍數追蹤**：
  - 國內股票、複委託、海外券商支援成員獨立之標的明細編輯彈窗。
  - 支援設定標的槓桿倍數（如正2槓桿填 `2`、反一填 `-1`、原型填 `1`），系統以帳面價值自動加總帶回主表維持會計平衡，並換算實質市場曝險與股票槓桿倍數（曝險 ÷ 淨資產）。
  - 提供即時算式顯示與 ⓘ 氣泡指引（風控門檻：≤1.0x 安全、1.0~1.5x 適度、>1.5x 警戒）。
- **個股與標的配置明細**：自動不分大小寫合併不同成員持有的同名標的，顯示標的槓桿標籤、帳面市值與資產佔比進度條。
- **多維度視覺化分析**：
  - 資產配置圓餅圖（Chart.js 動態繪製）。
  - 淨資產增長歷史趨勢圖。
  - 每月數據分析表：自動計算淨資產月增減金額、月增率（MoM）與年化複合成長率（CAGR）；累積不足 12 個月的年化率以灰字加 `*` 標示，僅供參考。
- **數據概覽**：提供「一鍵複製」會計資產負債結構化純文字，便於貼入外部 AI 工具進行深度財務諮詢。

### 💵 2. 收支損益與現金流量模組 (Income Statement & Cash Flow)
- **實質現金流入 (收入)**：薪資（`salary`）、其他流入（`other`）。
- **實質現金流出 (支出)**：
  - **借貸支出**：單獨拆分房貸、增貸、信貸、股票質押等融資成本，每筆貸款每月填寫一格：本+利貸款（一般房貸、增貸(一)、增貸(二)、信用貸款）填寫每月應繳總額（本金＋利息），理財房貸與股票質押填寫利息；所有數值存為 `interest`。注意：本+利的本金會計入現金流出，因此淨現金流即為含本金償還後的實際結餘；比照負債 6 大分類，直接於輸入表單中展開「一般房貸」、「增貸(一)」、「增貸(二)」、「理財房貸」、「信用貸款」與「股票質押」（各一格），各成員直接鍵入當月實付利息，免開彈窗直覺流暢，系統自動加總帶入損益分析並標準化留存項目明細。
  - **信用卡費1（`creditCard`）、信用卡費2（`creditCard2`）**：兩張（或兩類）信用卡當期應繳金額，分析畫面分開顯示；舊資料缺少 `creditCard2` 時視為 0。與其他流出的消費可能重複計算（B 做法），淨現金流會因此偏低。
  - **其他流出（`variable`）**：房租/管理費、保險、稅金、孝親費、伙食、交通、日常購物、娛樂休閒等。（其他流入、其他流出可點擊輸入明細，同資產明細彈窗但無槓桿欄，合計自動帶回主欄位）
- **現金流儀表板**：本月流入、本月流出、本月淨現金流（含儲蓄率）、借貸還款負擔比；另有今年累積淨現金流（位於成員篩選右側）。
- **趨勢與結構圖表**：每月流入/流出長條圖，搭配淨現金流折線；當月流出結構圓餅圖。
- **每月現金流表**：月份、流入、流出、淨現金流、儲蓄率。
- **數據概覽一鍵複製**：提供「一鍵複製」功能，將當期收支與財務指標彙整為標準純文字，利息項目自動標註 `[項目(金額)]` 明細，便於貼入外部 AI 工具進行諮詢。

### 🔒 3. 客戶端 AES-256 加密 (Security)
- **客戶端加密**：所有資產數據在瀏覽器端以 AES-256 加密後儲存於 `database.json`。
- **金鑰衍生強化（v2 格式）**：匯出時使用瀏覽器內建 WebCrypto，以 PBKDF2-SHA256（600,000 次迭代）由密碼衍生金鑰，再以 AES-256-GCM 加密（具完整性驗證），寫成 JSON 信封 `{"format":"financial-dashboard-vault","version":2,…}`。舊版 CryptoJS 密文（`U2FsdGVkX1…` 開頭）仍可正常解鎖，下次匯出即自動升級為 v2 格式。
- **解鎖速度**：PBKDF2 的慢速衍生是刻意設計，解鎖時按鈕會顯示「解密中…」；在較舊的手機上可能需要 1～2 秒。
- **安全解鎖螢幕**：網頁載入時強制顯示密碼解鎖介面；未加密的明文 `database.json` 會被拒絕載入。密碼只在瀏覽器內運算，不會上傳伺服器。
- **密碼輸入**：匯出時以遮罩彈窗輸入密碼（不預填）；初次設置或變更密碼時需二次確認，防止手民之誤導致歷史數據無法解開。
- **前端防護**：CDN 函式庫皆以 SRI 雜湊鎖定，並設有 Content-Security-Policy；所有顯示的資料皆經 HTML 轉義。
- **⚠️ 密碼強度仍然重要**：部署在 GitHub Pages 時 `database.json` 可被任何人下載並離線暴力破解；v2 格式讓每次猜測的成本提高數十萬倍，但仍請使用夠長且不重複的密碼。
- **需要 https 或 localhost**：WebCrypto 只在安全環境可用。若以 `http://192.168.x.x` 這類位址開啟，匯出會自動退回舊版格式並提示；v2 格式的檔案在這類環境無法解鎖。
- **資料防呆**：無法辨識的金額（如 `12a`）會標紅並阻擋套用與匯出；有金額但未填名稱的明細會保留為「未命名」；關閉有未儲存修改的明細彈窗時會先確認。

## 🛠️ 技術架構

- **前端技術**：純原生 JavaScript (Vanilla JS, ES6+)。
- **樣式庫**：Tailwind CSS (透過 CDN `@2.2.19`)，再以 `index.html` 內的 CSS 變數層統一配色（淺色「Clean Ledger」風格）；支援桌面雙欄與手機單欄響應式佈局 (RWD)，手機版輸入表單一次顯示一位成員。
- **圖表引擎**：Chart.js (透過 CDN `@3.7.0`)。
- **加密演算法**：WebCrypto PBKDF2-SHA256 + AES-256-GCM（v2 格式，瀏覽器內建）；CryptoJS (透過 CDN `@4.1.1`) 僅用於讀取舊版密文。
- **儲存格式**：靜態 `database.json`（相容舊版「數字」與新版「{ total, details }」兩種金額格式；載入時會先正規化：字串金額轉為整數、舊版 `real-estate` 鍵改為 `realEstate`、舊版 `dividend`、`fixed` 欄位移除）。
- **效能設計**：三個頁面只在顯示時渲染（隱藏頁面僅標記為過期）；圖表以就地更新取代重建；月份變更偵測以每筆紀錄的快取簽章比對，長期資料也不拖慢輸入。
- **託管環境**：支援 GitHub Pages 或任何靜態網頁伺服器。

## 🚀 使用流程

### 1. 本地預覽或部署
- **本地開啟**：推薦使用任意本地靜態伺服器開啟（例如 VS Code Live Server，或在專案目錄執行 `python3 -m http.server 8765` 後瀏覽 `http://localhost:8765/`）。
- **直接雙擊 index.html（file://）**：瀏覽器不允許網頁自行讀取旁邊的 `database.json`，解鎖畫面會顯示「選擇 database.json…」按鈕，手動選擇檔案後即可輸入密碼解鎖；匯出下載與其他功能不受影響。
- **GitHub Pages 部署**：推送到您的私人或公開 GitHub 倉庫，於 Repository Settings -> Pages 啟用部署即可。

### 2. 資料輸入與更新流程
1. 進入網頁，輸入「資產金庫密碼」解密查看當前財務數據（支援 `type="month"` 的瀏覽器會顯示月份選擇器；其他瀏覽器請直接輸入 `YYYY-MM`，格式錯誤時會標示並暫停記錄）。
2. 切換至「**財務數據輸入**」頁面：
   - 選擇欲紀錄或修改的月份（格式 `YYYY-MM`）。
   - 若選擇已有紀錄之月份，系統自動帶入當月所有資產、負債、收支與標的/利息明細。
   - 亦可點擊「**帶入最新一期**」快速複製上期數據作為基底。
   - 金額會自動加上千分位；每列右側顯示四位成員合計，底部固定列顯示總資產、淨資產（或流入、流出）與上一期的差異，差異異常大時以 ⚠ 提醒檢查是否打錯位數。項目名稱旁的 ⓘ 可查看填寫說明。
3. 填寫「🏛️ 資產與負債數據」與「💵 現金流數據」子分頁；進階使用者可切換到右側的「🧾 JSON 編輯（進階）」直接編輯解密後的完整資料（驗證通過後套用，仍需按「匯出」寫入檔案）。
4. 可自由切換月份填寫多筆紀錄，切換時修改會自動保留。確認無誤後點擊底部固定列的「**套用修改**」，儀表板與撤銷基準隨即更新（尚未寫入檔案）。上方「月份總覽」由舊到新列出最近 12 個月，更早的月份可從「更早的月份」下拉選單選取；標示 ✓（已匯出）、✏️ 未套用、● 已套用（未匯出）、＋ 編輯中（新月份）；要撤銷目前月份尚未套用的修改，點擊底部固定列的「撤銷本月修改」（還原為最後套用的版本）。
5. 全部完成後點擊「**匯出加密 database.json**」（會先自動套用所有未套用的修改），在密碼彈窗輸入金庫密碼進行 AES 加密並下載（整批只需輸入一次密碼）。
6. 將下載的 `database.json` 檔案覆蓋專案根目錄下的同名檔案，並推送到 GitHub 倉庫即完成儲存！
   > 未匯出的修改（含已套用）只存在於本次頁面中，匯出前重新整理頁面會遺失，離開頁面時會出現提示。
